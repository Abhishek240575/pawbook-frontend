Delivery & return rules
Set the return window to 0 to switch returns off. Keep the payout waiting period (Payouts tab) at least as long as the return window, so sellers are paid only after the return window closes; otherwise refunds are taken back from the seller's next payout.
Payout rules
Sellers are paid for delivered items only: price × quantity, minus the commission. Coupon discounts are paid by PawBook. The waiting period gives buyers time to report a problem before the money goes out. Changes apply to payouts recorded from now on.

Customer reviews
New reviews can only come from customers whose order was delivered (marked Verified). Older reviews from before this rule are shown without the badge. Hide reviews that are abusive, off-topic or contain personal details; hidden reviews no longer count towards ratings.
